# 支出・投資判断

支出の比較、割に合う条件の計算、小さく試す計画、試した結果の振り返りの 4 つの Skill。

[CFO](https://github.com/p-take55/aachat-cfo) の Skill のうち、支出・投資判断にあたるものを Plugin にまとめたものです。単独で入れても使えます。

## 同梱の Skill

| Skill | すること |
|---|---|
| `cfo-spend-decision` | ツール・外注・採用への支出を比べる |
| `cfo-decision-scenarios` | その支出が割に合う条件を計算する |
| `cfo-trial-plan` | 小さく試す計画を立てる |
| `cfo-trial-review` | 試した結果を見て、続けるかを決める |

## 使うときに

数字の元になる資料、扱う事業・期間・通貨、守りたい残高や使える予算を、要る範囲で渡してください。手元の資料からでも、使える接続からでも始められます。

- 実績・予定・仮定、利益と入出金、本人の工数を分けて扱い、分からない金額をゼロで埋めません。
- 外部サービスとつなぐ設定（MCP・認証）、定期実行、通知は同梱していません。
- 送金・注文・支払・借入・投資の取引・税の申告・契約の変更・外への送信はしません。この Plugin を入れたことを、それらの許可とは受け取りません。
