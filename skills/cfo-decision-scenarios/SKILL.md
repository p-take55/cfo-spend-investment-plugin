# 判断条件・シナリオの整理

支出比較の基準案、本人の判断基準、未確認の効果・費用・期間を読む。意思決定に効く変数だけを選ぶ。
期待効果が出るまでの時間、利用量、追加工数、継続費用等を変えて比較する。相互に依存する変数を独立として不自然な組み合わせにしない。
各ケースの増分費用・効果・資金影響を同じ期間で計算する。式と変数の範囲を示し、「何件使えば」「何時間減れば」等の境界へ落とす。任意の割引率や成功確率を標準値として押しつけない。

成果は推奨が成立する条件、成立しない条件、先に検証する仮定。不確実な効果を確定した利益と呼ばない。資金シナリオがあれば参照し、別計算なら前提を照合する。
本人の許容範囲が未指定なら案として返し、勝手に支出上限を決定しない。
